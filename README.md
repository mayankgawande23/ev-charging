# EVCharge Frontend

React 18 + Vite frontend for EV charging discovery, booking, and account management.

## Stack

- React 18
- Vite
- Tailwind CSS + CSS Modules
- Material UI
- Redux Toolkit
- React Router v6
- React Hook Form + Zod
- Axios
- Recharts
- Leaflet-ready map shell

## Run

1. Install dependencies with `npm install`
2. Start dev server with `npm run dev`
3. Build production bundle with `npm run build`

## Notes

- The app currently uses mock data shaped around the provided Spring Boot API contract.
- API services are organized so real endpoints can replace mocks incrementally.
